TSPL은 explicit size, gap, density, coordinates, text, barcodes, QR codes, bitmap placement가 필요한 label page에 자주 사용됩니다.

| Family | Builder | Notes |
| --- | --- | --- |
| Boxliy | `TsplBoxliy` | Label size, coordinates, text, graphics, barcodes, QR codes, images, and queries. |
| Aryten | `TsplAryten` | Inherits the public Boxliy TSPL surface. |
| Lin8inch | `TsplLin8inch` | Inherits Boxliy and adds 8-inch status, media, ribbon, presentation, and device-info extensions. |
