TSPL 通常用于标签页：明确尺寸、间隙、浓度、坐标、文本、条码、二维码和位图位置。

| Family | 构建器 | 说明 |
| --- | --- | --- |
| Boxliy | `TsplBoxliy` | 标签尺寸、坐标、文本、图形、条码、二维码、图片和查询。 |
| Aryten | `TsplAryten` | 继承 Boxliy TSPL 的公开指令面。 |
| Lin8inch | `TsplLin8inch` | 继承 Boxliy，增加 8 寸状态、介质、色带、出纸和设备信息扩展。 |
