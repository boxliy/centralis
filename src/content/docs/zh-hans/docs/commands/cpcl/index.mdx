CPCL 通常用于移动标签和页式热敏标签流程。NIB 目前提供 Boxliy 和 Aryten 两个 CPCL Family。

| Family | 构建器 | 说明 |
| --- | --- | --- |
| Boxliy | `CpclBoxliy` | 页面、走纸、文本、字体样式、线框、反显、条码、二维码、图片和查询。 |
| Aryten | `CpclAryten` | 继承 Boxliy CPCL 的公开指令面。 |
| Lin8inch | - | 目前没有 Lin8inch CPCL 构建器。 |
