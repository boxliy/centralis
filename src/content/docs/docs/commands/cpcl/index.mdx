CPCL is commonly used for mobile labels and page-style thermal label workflows. NIB currently exposes Boxliy and Aryten CPCL families.

| Family | Builder | Notes |
| --- | --- | --- |
| Boxliy | `CpclBoxliy` | Pages, feed, text, font style, lines, inverse areas, barcodes, QR codes, images, and queries. |
| Aryten | `CpclAryten` | Inherits the public Boxliy CPCL surface. |
| Lin8inch | - | NIB does not currently expose a Lin8inch CPCL builder. |
