CPCL 通常用於移動標籤和頁式熱敏標籤流程。NIB 目前提供 Boxliy 和 Aryten 兩個 CPCL Family。

| Family | 構建器 | 說明 |
| --- | --- | --- |
| Boxliy | `CpclBoxliy` | 頁面、走紙、文本、字體樣式、線框、反顯、條碼、二維碼、圖片和查詢。 |
| Aryten | `CpclAryten` | 繼承 Boxliy CPCL 的公開指令面。 |
| Lin8inch | - | 目前沒有 Lin8inch CPCL 構建器。 |

不要因為內容像標籤就直接選擇 CPCL。最終選擇要看實際機器型號。
